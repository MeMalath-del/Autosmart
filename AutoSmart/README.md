# 🚗 AutoSmart - سوق قطع غيار السيارات

<div dir="rtl">

سوق إلكتروني ذكي متخصص في بيع ووساطة وتوصيل قطع غيار السيارات، يربط بين أصحاب السيارات والبائعين وورش الصيانة عبر منصة رقمية موثوقة وسهلة الاستخدام.

## ✨ المميزات

### للعملاء
- 🔍 البحث المتقدم عن قطع الغيار حسب السيارة
- 🛒 سلة تسوق تفاعلية مع Livewire
- ❤️ قائمة المفضلة
- 📦 تتبع الطلبات
- ⭐ نظام التقييمات والمراجعات

### للبائعين
- 📊 لوحة تحكم متكاملة
- 📦 إدارة المنتجات والمخزون
- 🚚 إدارة الطلبات والشحن
- 📈 إحصائيات المبيعات
- 💬 استقبال طلبات قطع الغيار

### للإدارة
- 👥 إدارة المتاجر والموافقة عليها
- 📁 إدارة التصنيفات
- 🚗 إدارة ماركات وموديلات السيارات
- 📊 إحصائيات شاملة

## 🛠️ التقنيات المستخدمة

- **Laravel 12** - إطار العمل الخلفي
- **Livewire 3** - للتفاعلية بدون JavaScript
- **SQLite** - قاعدة البيانات
- **Bootstrap 5 RTL** - الواجهة الأمامية
- **Bootstrap Icons** - الأيقونات

## 📋 المتطلبات

- PHP 8.2+
- Composer
- SQLite

## 🚀 التثبيت

```bash
# استنساخ المشروع
git clone <repository-url>
cd AutoSmart

# تثبيت المتطلبات
composer install

# نسخ ملف البيئة
cp .env.example .env

# إنشاء مفتاح التطبيق
php artisan key:generate

# إنشاء قاعدة البيانات
touch database/database.sqlite

# تشغيل الـ migrations
php artisan migrate

# تشغيل الـ seeders (بيانات تجريبية)
php artisan db:seed

# إنشاء رابط التخزين
php artisan storage:link

# تشغيل السيرفر
php artisan serve
```

## 📂 هيكل المشروع

```
AutoSmart/
├── app/
│   ├── Http/
│   │   ├── Controllers/
│   │   │   ├── Admin/          # لوحة الإدارة
│   │   │   ├── Seller/         # لوحة البائع
│   │   │   └── Auth/           # المصادقة
│   │   └── Middleware/         # الصلاحيات
│   ├── Livewire/
│   │   └── Shop/               # مكونات المتجر التفاعلية
│   └── Models/                 # النماذج
├── database/
│   ├── migrations/             # جداول قاعدة البيانات
│   └── seeders/                # البيانات التجريبية
└── resources/
    └── views/
        ├── layouts/            # القوالب الرئيسية
        ├── livewire/           # واجهات Livewire

```
