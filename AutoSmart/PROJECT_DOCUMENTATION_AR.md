## نظرة عامة على المشروع

### الوصف
منصة إلكترونية متكاملة لبيع قطع غيار السيارات تدعم متعدد البائعين (Multi-vendor) مع نظام توصيل متكامل. المنصة تتيح للمستخدمين شراء قطع الغيار من متاجر متعددة، وتوفر نظام توصيل مع سائقي التوصيل، بالإضافة إلى العديد من الميزات المتقدمة.

### التقنيات المستخدمة
- **Framework**: Laravel 12.0
- **PHP**: ^8.2
- **Frontend**: Livewire 4.0, Tailwind CSS 4.0, Vite
- **Database**: MySQL/PostgreSQL (قابل للتخصيص)
- **Package Manager**: Composer, NPM

### المميزات الرئيسية
- منصة متعددة البائعين (Multi-vendor Marketplace)
- نظام توصيل متكامل مع سائقي التوصيل
- دعم أنواع مستخدمين متعددة (أفراد وشركات)
- نظام مزايدة على المنتجات
- عروض فلاش سيل (Flash Sales)
- باقات منتجات (Bundles)
- نظام نقاط الولاء
- برنامج الإحالة (Affiliate Program)
- نظام المحفظة الإلكترونية
- نظام التقسيط
- نظام الاشتراكات
- نظام كروت الهدايا

## الوحدات والخصائص الرئيسية

### 1. إدارة المنتجات

#### خصائص المنتج
- معلومات أساسية: الاسم (عربي/إنجليزي)، الوصف، SKU، باركود
- معلومات تقنية: رقم OEM، أرقام بديلة، الشركة المصنعة، بلد المنشأ
- التسعير: سعر أساسي، سعر التخفيض، سعر الجملة، سعر الشركات
- المخزون: الكمية، الكمية المحجوزة، حد المخزون المنخفض
- التوافق: ربط المنتج بسيارات محددة (Make, Model, Year)
- المواصفات: مواصفات تقنية مفصلة
- الصور: صور متعددة مع صورة رئيسية
- الحالة: نشط، معلق، مرفوض
- التصنيفات: مميز، الأكثر مبيعاً، وصول جديد

#### عمليات المنتج
- إضافة/تعديل/حذف المنتجات
- استيراد/تصدير المنتجات (CSV/Excel)
- تحديث المخزون
- إدارة الصور والمواصفات
- إدارة التوافق مع السيارات
- الموافقة على المنتجات (من قبل المدير)

### 2. نظام التسوق

#### عربة التسوق (Cart)
- إضافة المنتجات للعربة
- تحديث الكميات
- إزالة المنتجات
- تطبيق الكوبونات
- حساب التكاليف (المنتجات، الشحن، الضرائب)

#### قائمة الأمنيات (Wishlist)
- إضافة/إزالة المنتجات
- نقل المنتجات للعربة
- مشاركة قائمة الأمنيات

#### مقارنة المنتجات (Compare)
- إضافة منتجات للمقارنة
- عرض مقارنة تفصيلية
- إزالة المنتجات من المقارنة

### 3. نظام الطلبات

#### حالات الطلب
- `pending`: في الانتظار
- `confirmed`: مؤكد
- `processing`: قيد المعالجة
- `ready_for_shipping`: جاهز للشحن
- `shipped`: تم الشحن
- `out_for_delivery`: في الطريق للتوصيل
- `delivered`: تم التوصيل
- `completed`: مكتمل
- `cancelled`: ملغي

#### عمليات الطلب
- إنشاء الطلب من العربة
- تتبع حالة الطلب
- إلغاء الطلب (في حالات محددة)
- إعادة الطلب
- طباعة الفاتورة
- تتبع الشحن

#### معلومات الطلب
- معلومات الشحن
- معلومات الفوترة
- تفاصيل المنتجات
- الكوبونات المستخدمة
- نقاط الولاء المستخدمة
- مبلغ المحفظة المستخدم
- ملاحظات العملاء والمتجر

### 4. نظام التوصيل

#### إدارة السائقين
- تسجيل السائقين (أفراد/شركات)
