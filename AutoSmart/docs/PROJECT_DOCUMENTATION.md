## نظرة عامة

### عن المشروع

**AutoSmart** منصة تجارة إلكترونية متكاملة متخصصة في قطع غيار السيارات، تم تطويرها باستخدام:

| التقنية | الإصدار | الاستخدام |
|---------|---------|----------|
| Laravel | 12.x | إطار العمل الأساسي |
| PHP | 8.3+ | لغة البرمجة |
| Livewire | 3.x | الواجهات التفاعلية |
| Bootstrap | 5.3 RTL | تصميم الواجهات |
| SQLite/MySQL | - | قاعدة البيانات |

### مراحل التطوير

تم تطوير المشروع على **5 مراحل**:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           مراحل تطوير AutoSmart                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  المرحلة 1 ──► المرحلة 2 ──► المرحلة 3 ──► المرحلة 4 ──► المرحلة 5        │
│  الأساسيات     الإضافات      المتقدمة      الذكية       الاحترافية         │
│                                                                             │
│  • المتاجر     • الكوبونات    • سياراتي    • الأسئلة     • التسعير         │
│  • المنتجات    • المحادثات    • المدفوعات  • المزادات    • الذكي           │
│  • الطلبات     • العناوين     • المخزون    • التتبع      • نقاط البيع      │
```

## واجهات البرمجة API

### نقاط النهاية الرئيسية

```
API Endpoints (Sanctum Authentication)
═══════════════════════════════════════

المنتجات:
GET    /api/products              -- قائمة المنتجات
GET    /api/products/{id}         -- تفاصيل منتج
POST   /api/products/search       -- بحث متقدم

السلة:
GET    /api/cart                  -- عرض السلة
POST   /api/cart/add              -- إضافة للسلة
PUT    /api/cart/update/{id}      -- تحديث الكمية
DELETE /api/cart/remove/{id}      -- حذف من السلة

الطلبات:
POST   /api/orders                -- إنشاء طلب
GET    /api/orders/{id}           -- تفاصيل طلب
GET    /api/orders/{id}/track     -- تتبع الطلب

المصادقة:
POST   /api/auth/login            -- تسجيل دخول
POST   /api/auth/register         -- تسجيل جديد
POST   /api/auth/logout           -- تسجيل خروج
```

## التثبيت والتشغيل

### المتطلبات

```
PHP >= 8.2
Composer >= 2.0
Node.js >= 18 (اختياري للتطوير)
SQLite أو MySQL 8.0+
```

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone https://github.com/autosmart/autosmart.git
cd autosmart

# 2. تثبيت التبعيات
composer install

# 3. إعداد البيئة
cp .env.example .env
php artisan key:generate

# 4. إعداد قاعدة البيانات
touch database/database.sqlite
php artisan migrate --seed

# 5. ربط التخزين
php artisan storage:link

# 6. تشغيل الخادم
php artisan serve
```
